# プログラミング言語を見つける

多くのプログラミング言語があります。例えば Java, JavaScript, PHP, C, C++。

文字列 `subject:Java JavaScript PHP C++ C` からそれらを見つける正規表現を作成してください:

```js
let reg = /your regexp/g;

alert("Java JavaScript PHP C++ C".match(reg)); // Java JavaScript PHP C++ C
=======
